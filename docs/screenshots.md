# Documentation screenshots

The home, settings, and weather images use fictional programs, generic app tiles,
original landscape illustrations, and sample weather values. They are direct
captures of the launcher widgets on a Google TV Streamer, without streaming-service
artwork or account viewing data.

The original procedural illustrations and fictional metadata are dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The launcher interface retains its existing GPL license and upstream credits.

The generator, isolated demo entry point, and retake instructions are preserved on
the separate [documentation screenshot branch](https://github.com/niposch/LTvLauncher-Extended/tree/codex/documentation-screenshots/tool/screenshots).
To capture a newer version, merge `master` into that branch and follow its README.
The regular release build uses the normal entry point and contains no demo fixture.

Earlier screenshots have been removed from this repository's branch and tag
history. This changes commit IDs while retaining commit messages and authorship;
upstream commit links in the attribution document refer to their original source.
